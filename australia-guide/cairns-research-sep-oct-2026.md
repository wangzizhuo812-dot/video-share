## 1. Silverswift vs Reef Magic（外礁）

### 1.1 对照表

| 维度 | Silverswift（Quicksilver / Silverseries） | Reef Magic（Moore Reef 浮台） |
|------|-------------------------------------------|-------------------------------|
| 产品形态 | 高速双体船，**当日换 3 个外礁点**（Flynn / Pellowe / Milln / Thetford 等，按海况选） | **固定外礁浮台** Moore Reef（约 45 km） |
| 在礁时间 | 约 **5 小时**水中活动窗口 | 约 **5 小时**在浮台 |
| 船程 | 约 08:30 离港 → 约 16:30 回港；首站约 09:50 | 约 **90 分钟**单程；09:00 离港 → 17:00 回港 |
| 官方成人价 | **AUD 308**（含 EMC；价有效至 2027-03-31） | Off-peak **from AUD 325**；**Peak AUD 360**（2026-06-27～10-11 含你们 9/30） |
| 含餐 | 早茶/午茶 + 热带自助午餐 | 早茶/午茶 + Ochre 出品自助午餐 |
| 浮潜 | 无限浮潜 + 各点 briefing + guided snorkel | 无限浮潜 + 浮力衣/浮条；可选 Marine Biologist Safari（约 from AUD 75） |
| 不会游泳 | **弱**：几乎全靠水下；甲板休息可，但干式观礁设施少 | **强**：水下观景室、玻璃底船、半潜艇**含在票价**；可选 Sea Trek 头盔潜（约 from AUD 138，不湿发） |
| 晕船 | 双体 + ride control，但仍是**整日随船移动**；中文游记多次提醒易晕 | 同样有 90 分钟外海；到台后**船体不再连续颠簸**，干式活动可“上岸”缓冲 |
| 适合谁 | 会游、想多看几个点、可接受忙节奏 | 混编能力（有人不游）、轻松、带干式备选 |

### 1.3 晕船 / 不会游泳适配

- **官方**：Reef Magic 明确建议易晕者提前约 **30 分钟**服药；船上有 ginger / Travel-Calm。
- **本地经验**（[ilovecairns 晕船船推荐](https://www.ilovecairns.com.au/cairns-best-reef-trips-to-avoid-seasickness)）：平静日各船都 OK；担心时倾向稳定双体；**到浮台后干式活动**对晕船更友好。
- **中文可索引体验**：
  - [慢灵魂旅人 · Silverswift](https://slowsoultraveler.com/cairns-scuba-diving-silver-swift/)：外礁小船较颠，**开船前 30 分钟吃药**；船上或有中文教练；无半潜等干式设施。
  - [穷游问答 · Silverswift 晕船讨论](https://ask.qyer.com/question/86052.html)：多人反馈外礁船易吐。
  - [usihai 问答 · 银梭 vs Reef Magic](http://www.usihai.com/wenda/82849.html)：平台 vs 多点船的差异讨论（信息偏旧，作体验参考，价格以官网为准）。

**三人决策规则**

1. 任一人不会游泳或强烈怕晕 → **订 Reef Magic**（Peak **3×360 = AUD 1,080**）。
2. 三人都会游、追求水下多样性 → **Silverswift**（**3×308 = AUD 924**）。
3. 折中：订 Reef Magic，会游的人加 Snorkel Safari；不会游的人 Sea Trek / 玻璃底船。

来源：[BOM climate averages](https://www.bom.gov.au/climate/averages/tables/cw_031011.shtml) · [Tourism Australia Cairns weather](https://www.australia.com/en-us/facts-and-planning/weather-in-australia/cairns-weather.html)

**出行含义**

- 仍处干季尾声，适合出海/库兰达；湿度开始回升。
- **水母季**一般约 11 月～次年 5 月，9 月底通常不强制全身 stinger suit，但船方常提供 lycra；听当日 briefing。
- 东南信风仍可能让外海有涌浪——晕船预案不能省。
- 出发前看 [BOM marine](http://www.bom.gov.au/qld/forecasts/cairns.shtml) 与船公司短信。

## 9. 风险清单

1. **Skyrail 改造**：完整缆车体验缺失；周一/二无 Loop；日期变更需重核 [upgrade 页](https://skyrail.com.au/upgrade/)。  
2. **外礁风浪取消/改点**：备绿岛或市区；买可改期产品更稳。  
3. **晕船**：外礁 90 min+；药要提前提醒全员。  
4. **不会游泳误订 Silverswift**：体验落差大 → 优先平台。  
5. **飞潜间隔**：若体验潜水，按船方建议 **12–24h 内勿升高海拔/登机**（Silverswift 文案：多潜后最好 24h）。你们 10/3 起飞 → **9/30 潜水需谨慎**，浮潜相对宽松但仍遵 briefing。  
6. **床型不符**：Dual Key 常是两张 Queen；务必书面确认。  
7. **国庆中文团 dual**：码头/库兰达更挤，早到 check-in。  
8. **价格变动**：Peak/燃油附加费/EMC 以付款页为准。
