回程

机场怎么选

首选广州 CAN 开口程

  1. 推荐：CAN → SYD，MEL → CAN。两头均有南航日班直飞，回程傍晚到广州，方便回深圳。
  2. 比价：HKG → SYD，MEL → HKG。航司更多；三人合计至少便宜约 ¥2,500，或时刻明显更好时才跨境。
  3. 弱备选：SZX。深航有深圳↔墨尔本（周 3 班），但与「先悉尼、10/7 回」对不上；深圳↔悉尼班期需临订核验。
  4. 拒绝默认：澳门。往澳多为中转，口岸+船班成本高。

深圳机场↔香港机场客船已于 2026/3/16 起停航。完整对比、拒绝条件与来源见 交通住宿。

2男1女住宿

订房重点不是“可住3人”

  • 优先找 2-bedroom apartment，1 Queen + 2 Single：女生单独一间，两位男生各睡单人床。
  • 筛选必须写 3 adults；“可住 3 人”常实际是两张双人床或一张沙发床。
  • 最好 2 卫、洗衣机、厨房，12 晚会舒服很多。
  • 找不到合适床型时，订 1 间单人房 + 1 间 Twin Room，不要默认三人挤标准双床房。

住宿区域：悉尼优先 CQ–Town Hall 走廊 2 卧（Pullman Quay Grand / Meriton / Adina DH，见悉尼调研）；凯恩斯 Esplanade；墨尔本 CBD / Southern Cross（Aura / Brady / Oaks / Sebel Docklands）。

三人预算

舒适档约 ¥7.2万–10.5万

  • 国际开口程：¥18,000–30,000
  • 澳洲国内两段：¥5,000–9,000
  • 2 卧公寓 12 晚：¥16,000–26,000

约 ¥24,000–35,000/人。国庆重叠期，机票和 2 卧公寓是最大变量；当前应优先锁可退住宿和国际机票。

这个版本主动舍弃

不去圣灵群岛，也不硬塞企鹅岛

  • 凯恩斯外礁已经承担“海”的核心体验；再加圣灵需额外转场，12 晚会明显变赶。
  • 大洋路前一天保留市区恢复，回程前不再安排菲利普岛深夜团。
  • 如果你们更想看白天堂沙滩，可把凯恩斯 4 晚整体换成 Airlie Beach，而不是两个都去。

这是以“不太累”为第一优先的取舍，不是景点越多越好。

2. 跨境 / 高铁 / 机场衔接

去 CAN（推荐路径）

  • 9/24 下午：深圳 → 白云机场；国际航班建议起飞前 ≥3 小时到场。
  • 空港快线（八卦岭候机楼等）常态约每小时一班，末班常约 17:30，车程约 150–180 分——若赶 21:00 航班，最迟应赶上 16:00 前班次，堵车再提前。
  • 备选：深圳北/福田高铁→广州南→地铁 3 号线机场南/北；总耗时常接近巴士，但延误更可控。
  • 回程 10/7 傍晚抵 CAN 后，反向空港快线或高铁回深圳，当天勿排景点。

去 HKG（备选路径）

  • 广深港高铁福田/深圳北→西九龙：二等座约 ¥68/¥75，车程约 14–25 分；口岸一地两检。
  • 西九龙步行经行人通道接九龙站，乘机场快线至机场约 22 分；成人八达通/银行卡约 HK$105。
  • 运输署：西九龙站开放约 6:00–24:00；机场快线九龙站约 5:53–0:52。
  • 已失效旧攻略：深圳机场码头↔香港机场海天码头客船，深圳机场官网称 2026/3/16 起停航。
  • 中秋假期首日前后口岸易堵，9/24 傍晚过关请额外留 60–90 分缓冲。

3. 澳洲国内航班时段与行李票价坑

  • SYD→CNS（约 9/29）：优先 10:00–14:00 直飞（约 3h10），留足国际转国内取行李+安检时间；避免太早导致酒店凌晨退房。
  • CNS→MEL（约 10/3）：优先上午/中午直飞（约 3h20），尽量在 10/4 夏令时切换前抵达并安顿。
  • Jetstar Starter：默认仅手提合计 7kg；托运须网购加购。机场首购国内 20kg 约 AUD $120，远贵于预订时加购——三人最易踩坑。
  • Virgin Lite（2026/2/2 起）：经济舱手提 1 件≤8kg + 个人物品；Lite 不含托运，需买 Choice/加购。
  • 更稳妥：Qantas 或 Virgin Choice（含 23kg 托运）——三人各有大箱时，总价常接近“廉航票面+三份行李+选座”。
  • 中文攻略常见坑：① 以为“国际行李额能带到国内段”（分票不行）；② 登机口才秤重；③ 只看 Starter 票面；④ 超大件另收搬运费。

4. 2 男 1 女 · 2 卧床型怎么订

  1. 第一优先：整租 2-bedroom（Airbnb/Booking 公寓）。搜索关键词 2 bedrooms + 入住人数选 3 adults；确认床型图文为 1 Queen（或 King）+ 2 Single，或两间独立卧室。
  2. 第二优先：酒店 Family / Triple，但许多酒店写明 bed type is request only，Twin 可能是 zip-king 拆分——下单后发邮件锁定床型。
  3. 第三优先：1×Single + 1×Twin（两间房）：女生单间，两男双床；总价可能高于 2 卧公寓，但隐私最好。
  4. 拒绝：仅标注 sleeps 3、实际为 1 大床+沙发床；或 Family 限 2 成人+儿童。
  5. 区域：悉尼 Town Hall/Wynyard；凯恩斯 Esplanade/Reef Fleet；墨尔本 CBD/Southern Cross。

朋友提到的几个点 · 深度调研

使徒岩、大堡礁/圣灵群岛、悉尼墨尔本城里逛——哪些必去、哪里有坑、12 天怎么排。

重点 ① · 墨尔本周边

十二门徒岩（Twelve Apostles）

朋友说「非常震撼、照片拍不出效果」——基本属实。现场是南大洋风浪拍崖、石灰岩柱立体感，手机/网图很难还原尺度与声响。

  • 它是什么：大洋路上的石灰岩海蚀柱，现可见约 7–8 根（名字是诗意命名，不是真有 12 根；多年来有柱子倒塌）。
  • 怎么去：墨尔本单程约 3–4.5 小时（沿海风景线更长；内陆高速更快）。一日游约 12 小时，坐车多、走路少——适合「不想太累」但仍想看震撼景。
  • 最佳光线：日出/日落最美；普通一日游多是中午到达，观感仍震撼但光线偏平。有预算可加直升机 10–15 分钟（约 AUD 150–180）。
  • 门票：观景台免费；停车走木栈道约 45–60 分钟足够。
  • 轻松建议：报小团一日游即可，不必自驾；想更松可住 Port Campbell 一晚看日落，但会占掉市区时间。

结论：12 天行程里 强烈建议保留，是墨尔本段的核心体验。

重点 ② · 昆士兰

大堡礁 + 圣灵群岛（Whitsundays）

朋友说「听老中说不如东南亚的海」——要分清你比的是什么。珊瑚密度/生物多样性，顶尖东南亚（如印尼四王群岛）常更密；但大堡礁是世界最大礁系，澳洲出海服务规范、安全，体验类型也不同。

  • 大堡礁 ≠ 圣灵群岛：圣灵群岛在礁区范围内，但强项是白天堂沙滩 Whitehaven + 帆船岛景；真正浮潜看珊瑚，多数人评价 凯恩斯外礁比圣灵近岸礁更好（船程更短、外礁选择更多）。
  • 「不如东南亚」常见原因：① 近岸/热门点珊瑚白化或沙覆盖；② 船多、团多；③ 期望按马尔代夫/菲律宾那种「跳岛即天堂」来比。选外礁一日游或干季（约 5–10 月）会好很多。
  • 圣灵群岛怎么去：基地是 Airlie Beach（艾尔利海滩）或汉密尔顿岛，不是凯恩斯市区。凯恩斯开车约 7 小时，或飞 Proserpine/Hamilton；去 Whitehaven 没有普通轮渡，必须报船/帆船/水上飞机。
  • 12 天轻松版怎么选：
    A. 推荐：凯恩斯做大堡礁一日游（看礁）——省事、少转机。
    B. 想看白沙滩：把昆士兰段改成 Airlie 2–3 天（圣灵）——看岛景，珊瑚可能不如凯恩斯外礁。
    C. 两个都去：至少多加 2–3 天 + 多一段机票，会变赶，不适合「不要太累」。

结论：轻松 12 天优先 凯恩斯外礁；圣灵当「升级选项」，别硬塞进同一周。

重点 ③ · 双城慢逛

悉尼 + 墨尔本城里逛一逛

朋友说得对：两城最适合步行慢逛，景点集中，不用天天报团。各留 1.5–2 天市区就很舒服。

  • 悉尼经典半日–一日（几乎全步行/渡轮）： 环形码头 → 歌剧院外观 → 皇家植物园 → Mrs Macquarie’s Chair（歌剧院+大桥同框）→ The Rocks 岩石区 → 傍晚回 Circular Quay。第二天可渡轮去 Manly。
  • 墨尔本经典一日（CBD 有免费电车区）： 弗林德斯街车站 → 圣保罗教堂 → Hosier Lane 涂鸦巷 → 联邦广场 / NGV → 皇家拱廊 & Block Arcade → 州立图书馆穹顶 → 维多利亚市场（注意周一常休市）→ 唐人街或巷弄吃晚餐。
  • 两城气质差：悉尼是「海港大场面」；墨尔本是「巷弄、咖啡、文艺」。别急着打卡完，留空档喝杯 Flat White。
  • 交通：悉尼用 Opal 卡；墨尔本用 myki，CBD Free Tram Zone 内可免费坐电车。

结论：市区慢逛是「恢复体力日」，和大洋路、出海交替安排刚刚好。
