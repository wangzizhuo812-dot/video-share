## 1. 出发与抵达（广州 / 香港）

### 1.1 广州 CAN → 悉尼 SYD（首选）

- 直飞运营商公开索引为 **China Southern（南航）**；平均航程约 **9h25m**。
- 典型夜航窗口：**约 20:50–21:00 起飞 → 次日约 08:25–09:25 抵达 SYD T1**（以实际订票时刻为准）。
- 来源：[FlightConnections CAN–SYD](https://www.flightconnections.com/cn/%E4%BB%8E-can-%E9%A3%9E%E5%BE%80-syd-%E7%9A%84%E8%88%AA%E7%8F%AD)（页面标注更新至 2026-08）；CZ325 动态可参考 [Trip.com CZ325](https://hk.trip.com/flights/status-cz325/)。

**操作建议（深圳 base）：** 9/24 下午深圳→广州白云；国际航班建议提前 **≥3 小时**到机场。

### 1.2 香港 HKG → SYD（比价备选）

- 多家航司有直飞，飞行约 9 小时量级；适合三人合计明显更便宜或时刻更好时选用。
- 坑：蛇口/机场快船过境需合资格航司 + 同日转机余量；抵港后回深圳更晚。

### 1.3 入境

- 中国护照旅客需事先办 **ETA / 签证**（官方 AustralianETA App 或 ImmiAccount）。中文攻略共识：[Cosmopolitan HK 悉尼攻略](https://www.cosmopolitan.com.hk/lifestyle/sydney-travel)、[Footprint Backup](https://footprintbackup.com/sydney-travel-guide/)。
- 不在此虚构办理时长与费用；以澳大利亚内政部实时页面为准。

## 3. 适合住的区域 + 2卧（1 Queen + 2 Single）候选

### 3.1 区域排序（轻松版）

中文游记与官方旅游站共识（[Ms Wanders](https://mswanders.com/australia-sydney-travelinfo/)、[sydney.com](https://www.sydney.com/)）：

| 优先级 | 区域 | 优点 | 缺点 |
| --- | --- | --- | --- |
| ★★★ | **Circular Quay / The Rocks / Quay Quarter** | 歌剧院、渡轮、市集步行可达 | 最贵、游客多 |
| ★★★ | **CBD：Town Hall / Wynyard / World Square** | 火车轻轨地铁齐、去蓝山接送方便 | 工作日吵 |
| ★★☆ | **Darling Harbour / Pyrmont / Barangaroo** | 水岸散步、餐饮多、公寓供给足 | 到 Circular Quay 常需 15–25 分钟步行/轻轨 |

## 6. 蓝山：跟团还是自助？

| 维度 | 跟团一日游 | 火车自助 |
| --- | --- | --- |
| 门到门 | 酒店接送，约 **10 小时**整包 | Central↔Katoomba 约 1.5–2h×2 + 当地公交/Explorer Bus |
| 费用结构 | 团费常含接送±Scenic World（公开区间常被写成约 AUD 120–200+/人，**以报价单为准**） | Opal 车费 + Scenic World 门票 + 可选 Explorer Bus |
| 体力/脑力 | 低——适合落地第 4 天、三人不全熟英语公交 | 中——要对时刻、686 公交/Explorer、回程末班 |
| 灵活度 | 低 | 高；可错峰下午去 Scenic World 避团客 |
| 官方信息 | Visit NSW 列 Oz Trails / Anderson’s / Picture Me 等 | [Visit NSW getting there](https://www.visitnsw.com/destinations/blue-mountains/getting-to-the-blue-mountains)；Katoomba 当地公交可用 Opal |

**本行程结论（2男1女 · 偏轻松 · 周一）：优先跟团。**

理由：周一工作日团客仍多但节奏可控；自助早班 + 换乘对「不要太累」不友好；三人分摊团费后与「火车+门票+时间成本」差距缩小。若有一人特别想慢走 Leura 书店咖啡、且愿意 06:30 前出门，再改 **火车 + Blue Mountains Explorer Bus**。

注意（Visit NSW）：Great Western Highway / Jenolan 部分路段曾有封闭与改道信息——**自驾团/自驾需查 TfNSW 路况**；本推荐跟团一般已含司机路线。

渡轮本身仍值得坐（港景在阴天也成立）。上岸后：

| 方案 | 内容 | 说明 |
| --- | --- | --- |
| A. 仍去 Manly | Corso 室内店、咖啡馆；缩短海滩停留；取消 Shelly | 雨衣+防滑鞋 |
| B. 改室内主线 | **QVB** → **Hyde Park / St Mary’s** → **Australian Museum**（收费）或 Art Gallery of NSW | 全步行/短公交 |
| C. 达令港室内 | **SEA LIFE Sydney Aquarium**（建议预约时段） | 雨天亲子/轻松杀手锏；[visitsealife](https://www.visitsealife.com/sydney/) |
| D. 半日动物园 | F2 **Taronga**（12 min 渡轮）+ 室内展馆 | 雨天部分室外展不便；查开园 |
| E. Manly 本地室内 | Escape rooms、画廊等 | [Escape This Manly](https://www.sydney.com/destinations/sydney/sydney-north/manly/attractions/escape-manly)；小众 |

**决策树：** 仅飘雨 → 仍去 Manly；持续中到大雨+大风（渡轮可能颠簸）→ 改 C 或 B，把 Manly 与 Bondi 对调到周二晴窗（若还未飞走）。

### 9.1 建议提前订

7. 旅行保险、eSIM  

### 9.2 常见坑（中文攻略 + 官方交叉）

| 坑 | 实情 |
| --- | --- |
| 机场火车「很贵」 | 贵在 **进站费**；三人行李多时 taxi 固定价试验可能更划算 |
| 以为日上限含机场费 | **不含**；进站费单独封顶 |
| 忘记 tap off | 可能被扣默认最高票价 |
| 岩石区市集「每天都有」 | 主市集 **五/六/日**；平日没有同款规模 |
| 落地日排满海港+Bondi | 时差+步行量，轻松游会崩 |
| 蓝山自助却订下午才出门 | 回程火车间隔约 1h，天黑早（春分后渐好）仍易赶 |
| Jenolan 洞穴跟蓝山打包 | 部分路段/洞穴曾长期关闭；以 Visit NSW 为准，本轻松行程不塞洞穴 |
| 护照拍卡失败 | 部分中国银联卡不受理；备 Visa/MC 或实体 Opal（机场可买，机场购卡/充值有最低额规则） |
| 阳光 | 春季 UV 仍高；帽子+防晒（中文攻略反复强调） |

## 10. 与「小红书风」中文攻略对齐后的取舍

公开可索引的中文/华文行程（KKday、Ms Wanders、Reese Travel、Trip.com 慢游等）通常把 5 天写成：市区地标 + 蓝山 + 海滩/动物园。本方案对齐其模块，但按**偏轻松**做了减法：

- 保留：海港步行、Manly 渡轮、蓝山、可选 Bondi 半日  
- 降级/不硬塞：Harbour Bridge Climb、Taronga 全天、Bondi→Coogee 全程 6 km、猎人谷  
- 把动物园留给「雨天/替换日」，不与 Manly、蓝山抢体力
