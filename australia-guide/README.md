# 慢游澳洲 · 12 天轻松攻略

图文并茂的澳大利亚旅行计划（悉尼 → 凯恩斯 → 墨尔本），含静态中文景点地图。

## 本地打开

直接用浏览器打开：

```bash
open australia-guide/index.html
```

或起一个本地静态服务：

```bash
cd australia-guide && python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 内容包括

- 12 天轻松节奏日程（图文对照）
- 悉尼 / 凯恩斯与圣灵 / 墨尔本 / 总览静态景点地图
- 单人花销参考与实用贴士

地图为页面内置 SVG，不需要联网或第三方地图组件。景点配图来自 Unsplash。
