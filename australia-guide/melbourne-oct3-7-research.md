## 1. CNS–MEL 抵达后机场交通

### 1.1 航班概况（核验）

- 直飞约 **3h20–3h30**；承运：Jetstar / Qantas / Virgin。
- Jetstar 多抵 **T4**；Qantas 多抵 **T1**；Virgin 多抵 **T3**（以当日登机牌为准）。
- 建议选 **上午/中午前起飞**，10/3 下午有余力入住+轻逛（与总行程「夏令时前抵达」一致）。

### 1.2 推荐：SkyBus Melbourne City Express

| 项目 | 核验结果 |
|------|----------|
| 路线 | MEL（T1/T3/T4 路边站）↔ Southern Cross Station |
| 班次 | 约 4:00–1:00；高峰约每 10 分钟，非高峰约 15 分钟；**1:00–4:00 停运** |
| 车程 | 约 **30–45 分钟**（拥堵可达约 60 分钟） |
| 票价（调研时官网） | 成人单程 **AUD $25.90**；往返 **$43.40**（约合单程 $21.70） |
| 购票 | skybus.com.au / App / 航站楼 e-kiosk；票 12 个月内有效，**无需订具体班次** |
| 与 myki | **SkyBus 不接受 myki**，需单独购票 |

**三人建议**：提前网上买 **3× 往返**（10/3 进城 + 10/7 返机场），合计约 **AUD $130.20**。  
若行李多且三人同行，也可比价 Uber/出租车（约 AUD $65–85 量级，视时段），人均有时接近 SkyBus。

来源：  
- [Melbourne Airport – Bus Services](https://www.melbourneairport.com.au/bus-services)  
- [SkyBus City Express fares](https://www.skybus.com.au/melbourne-city-express/fares)  
- [SkyBus City Express](https://www.skybus.com.au/melbourne-city-express/)

### 1.3 备选：PTV 公交 + 火车（省钱但慢）

- 从 T4 Ground Transport Hub 乘 PTV 公交再转火车，需 **myki**，全程约 **75–90 分钟**。  
- 偏轻松、有行李时 **不推荐** 首日使用。  
来源：[Melbourne Airport bus services](https://www.melbourneairport.com.au/bus-services) · PTV 行程规划

## 2. CBD Free Tram Zone / myki

### 2.1 Free Tram Zone（官方）

- **范围内坐 tram 免费**，**不需要** myki，也 **不要误触碰**（误 touch on 会被扣 2 小时票价）。
- 范围概要：Queen Victoria Market ↔ Docklands ↔ Spring Street ↔ Flinders Street Station / Federation Square。
- 边界站有标识；出区必须 touch on。

来源：  
- [Transport Victoria – Cheaper travel with myki](https://transport.vic.gov.au/tickets-and-myki/myki/cheaper-travel-with-myki)  
- Free Tram Zone 地图 PDF（PTV/Transport Victoria 发布）

### 2.2 myki 怎么买、怎么用（2026 调研时）

| 项目 | 说明 |
|------|------|
| 实体卡 | 全票卡面值约 **$6**（另需充值）；车站/零售点可买 |
| Mobile myki | **Android + Google Wallet**；iPhone 通常仍需实体卡 |
| 何时需要 | 出 Free Tram Zone（如 Carlton、St Kilda、机场公交等） |
| 2026 票价（1 月起官方） | 全票日封顶 **$11.40**；周末/公休日封顶 **$8.00** |
| **半价政策** | 2026-06-01 至 2027-01-01，维州公共交通 **全员半价** → 日封顶约 **$5.70**（周末约 **$4.00**）；**不含 SkyBus** |

**三人偏轻松建议**：若全程几乎只在 CBD Free Tram Zone，可 **不买 myki**；若计划 Carlton / Fitzroy / St Kilda，买 1–2 张卡并充 **AUD $20–30/人** 足够（半价期内更省）。

来源：  
- [Public transport fares from 1 Jan 2026](https://transport.vic.gov.au/news-and-resources/news/public-transport-fares-from-1-january-2026)  
- [vic.gov.au – Half price travel](https://www.vic.gov.au/half-price-travel)

## 5. 大洋路「反向」小团：选择标准与耗时

### 5.1 为什么选反向（中文游记 + 运营商共识）

1. **先到十二门徒**：避开顺向大巴下午拥堵。  
2. **光线**：上午/中午对岩柱多为更友好的拍摄光（中文语境常称「不逆光」）。  
3. **回程走海岸**：下午经 Apollo Bay / Lorne / 牌楼，节奏更松。

### 5.2 选择标准（清单）

| 标准 | 建议 |
|------|------|
| 团型 | **≤12–14 人** 精品小团（HiAce / 奔驰保姆车）；避免 28–55 座大巴若追求「偏轻松拍照」 |
| 路线关键字 | **Reverse / 反向 / 逆向**，明确 **先 Twelve Apostles** |
| 时长 | **约 12–13 小时**（CBD 出门到回家） |
| 接送 | CBD / 酒店上门或固定集合点；确认步行距离与等候规则 |
| 语言 | 需要中文讲解选中文司导团；英语团配多语音频亦可 |
| 含不含餐 | 多数 **午餐自理**；备澳币现金小费（中文团常见 **AUD $5/人**） |
| 体力 | 短距离观景步道为主，适合「不想太累」；仍是超长日，需前一晚早睡 |
| 取消政策 | 常见出发前 7 天内不可退——尽早订 10/6 |
| 价格带（参考） | 英文精品约 AUD **130–200+**；中文反向促销可见约 **90–175**（随季波动） |
